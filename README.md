# GradTrack 2027 – daily job list

`jobs.json` is the list of UK graduate schemes (2027 starts) that every copy of GradTrack downloads when it opens.
It is updated once a day. Each role follows the format in `SPEC.md` (entry requirements are structured so the tracker can filter by degree subject, A-levels/UCAS points, GCSEs, degree class, location and driving licence).

Please don't edit by hand unless you know the format – an invalid file is ignored by the tracker, which then falls back to the last good list.
